# Prompt: Video From Book Metadata

## Input

- 書名
- 副標
- 類別
- 目標讀者
- CTA
- 平台

## Output Requirements

請輸出以下段落：

1. `HOOK`
2. `60秒腳本`（含時間節奏）
3. `STORYBOARD`（逐段畫面）
4. `VISUAL BEATS`（畫面節奏與轉場）
5. `CTA`（平台導向）
6. `HYPERFRAMES COMPOSITION DIRECTION`（HTML 結構、clip 時間、動畫節奏）

## Constraints

- 以可轉換為 HyperFrames HTML composition 為目標
- 優先 1:1 社群短片
- 語氣專業、清晰、可執行

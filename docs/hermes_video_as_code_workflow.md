# Hermes Video-as-Code Workflow

## End-to-End Chain

Book metadata
→ Hook
→ SCRIPT.md
→ STORYBOARD.md
→ DESIGN.md
→ composition.html
→ HyperFrames render
→ MP4
→ LinkedIn / X / Blogger campaign
→ DMN memory feedback

## Delivery Model

- local-first
- agent-editable
- template-first
- ebook marketing oriented
- no external API required

## Future Integration Points

- `VendorProductData`: map metadata and campaign context into script generation inputs.
- LinkedIn marketing calendar: connect publication windows and template selection.
- Book cover assets: standardize `video/assets/covers/` ingestion in compositions.
- DMN performance memory: write campaign outcomes into append-only memory for iteration.
- Campaign logs: map render + publish events into structured logs for auditing.

## 1. Layer Definitions

**Source:** `memory/ontology/layer_definition.py`

### MemoryLayer Enum (`IntEnum`)

| Value | Name |
|-------|------|
| 1 | `L1_EPISODIC` |
| 2 | `L2_INSTINCT` |
| 3 | `L3_SKILL` |
| 4 | `L4_STRATEGIC` |

### LayerDefinition Dataclass

Fields: `layer`, `name`, `description`, `retention_policy`, `promotion_threshold`, `decay_rate`, `max_entries`, `governance_required_for_promotion`

### LAYER_REGISTRY Values

| Layer | name | description | retention_policy | promotion_threshold | decay_rate | max_entries | governance_required |
|-------|------|-------------|------------------|--------------------:|----------:|-----------:|:-------------------:|
| L1_EPISODIC | Episodic | Raw episodic memory — unprocessed observations and events | 30d | 0.7 | 0.1 | 10,000 | No |
| L2_INSTINCT | Instinct | Atomic reusable observations distilled from episodic patterns | 180d | 0.8 | 0.03 | 5,000 | Yes |
| L3_SKILL | Skill | Clustered workflows and procedures validated across contexts | 365d | 0.9 | 0.01 | 1,000 | Yes |
| L4_STRATEGIC | Strategic | Decision heuristics and metacognitive rules — highest-trust memory | unlimited | -1.0 (N/A) | 0.003 | 200 | Yes |

**Note:** L4 `promotion_threshold = -1.0` because L4 is the terminal layer — nothing promotes beyond it.

## 3. Decay Rules

**Source:** `memory/ontology/decay_rules.py`

### DecayRule Dataclass

Fields: `layer`, `base_rate_per_day`, `inactivity_multiplier`, `inactivity_threshold_days`, `contradiction_penalty`, `min_confidence`, `description`

### DECAY_RULES (4 rules)

| Layer | base_rate/day | inactivity_multiplier | inactivity_threshold_days | contradiction_penalty | min_confidence | description |
|-------|:-------------:|:---------------------:|:-------------------------:|:---------------------:|:--------------:|-------------|
| L1_EPISODIC | 0.1 | 2.0 | 7 | 0.05 | 0.01 | Episodic memories decay fastest |
| L2_INSTINCT | 0.03 | 1.5 | 30 | 0.1 | 0.05 | Instincts decay moderately |
| L3_SKILL | 0.01 | 1.3 | 90 | 0.15 | 0.1 | Skills decay slowly |
| L4_STRATEGIC | 0.003 | 1.1 | 365 | 0.2 | 0.2 | Strategic rules decay very slowly |

### DECAY_RULE_REGISTRY

`dict[MemoryLayer, DecayRule]` — keyed by layer for O(1) lookup.

### Decay Computation Functions

| Function | Formula | Description |
|----------|---------|-------------|
| `compute_decay(entry, rule, current_time)` | `conf × exp(-rate × elapsed_days)` | Rate multiplied by `inactivity_multiplier` if inactive beyond threshold; clamped to `min_confidence` |
| `should_remove(entry, rule)` | `conf <= min_confidence` | Returns `True` if entry has decayed below minimum |
| `_last_access_time(entry)` | Checks `last_accessed`, `last_validated`, `last_executed`, `last_applied` | Extracts most recent access timestamp |

## 4. Confidence Model

**Source:** `memory/ontology/confidence_model.py`

### ConfidenceUpdate Dataclass

Fields: `entry_id`, `previous_confidence`, `new_confidence`, `reason`, `timestamp`

### ConfidenceHistory

Append-only audit trail of all confidence changes.

| Method | Signature | Purpose |
|--------|-----------|---------|
| `append(update)` | `ConfidenceUpdate → None` | Add update to trail |
| `get_history(entry_id=None)` | `str|None → list[ConfidenceUpdate]` | Filter history by entry ID |
| `__len__()` | `→ int` | Total update count |
| `to_list()` | `→ list[dict]` | Serialize all updates |

### ConfidenceModel

Central authority for all confidence mutations. All changes go through `_make_update()` which clamps values to `[floor, 0.99]` and records in history.

| Method | Formula | Reason Tag |
|--------|---------|------------|
| `update_on_success(entry)` | `conf + 0.05 × (1.0 - conf)` | `"reuse_success"` |
| `update_on_failure(entry, rule=None)` | `conf - 0.1 × conf` | `"reuse_failure"` |
| `update_on_contradiction(entry, rule=None)` | `conf - contradiction_penalty` | `"contradiction"` |
| `update_on_access(entry)` | `conf + 0.01 × (1.0 - conf)` | `"validation"` |
| `apply_decay(entry, elapsed_days, rule)` | `conf × exp(-base_rate × elapsed_days)` | `"decay"` |

**Clamping:** `_clamp(value, floor=0.0, ceiling=0.99)` — confidence is always in `[floor, 0.99]`.

## 6. Promotion Engine API Surface

**Source:** `memory/ontology/promotion_engine.py`

### Data Classes

**`PromotionCandidate`** — Fields: `entry_id`, `source_layer`, `target_layer`, `confidence`, `evidence`, `eligible`, `blocking_reasons`, `proposed_at`, `candidate_id` (auto-generated UUID hex[:12])

**`PromotionResult`** — Fields: `candidate`, `approved`, `new_entry_id`, `governance_decision_id`, `verifier_id`, `reason`

### PromotionEngine Class

Constructor: `PromotionEngine(rules: list[PromotionRule], confidence_model: ConfidenceModel)`

| Method | Signature | Description |
|--------|-----------|-------------|
| `scan_candidates(entries, layer)` | `(list[Any], MemoryLayer) → list[PromotionCandidate]` | Find all entries eligible for promotion from a given layer |
| `propose_promotion(candidate)` | `PromotionCandidate → PromotionCandidate` | Register proposal in pending queue (does NOT auto-promote) |
| `approve_promotion(candidate_id, governance_decision_id, verifier_id=None)` | `(str, str, str|None) → PromotionResult` | Approve and execute promotion; requires `governance_decision_id`; L3→L4 requires `verifier_id` |
| `reject_promotion(candidate_id, reason)` | `(str, str) → PromotionResult` | Reject a pending candidate |
| `rollback_promotion(promotion_result)` | `PromotionResult → bool` | Reverse a previously approved promotion |
| `audit_log()` | `→ list[dict]` | Return all promotion decisions as audit trail |
| `get_pending()` | `→ list[PromotionCandidate]` | Return all pending candidates |

### Rejection Paths

| Scenario | Action Logged | Reason |
|----------|---------------|--------|
| Candidate not found | — | `"Candidate not found"` |
| Candidate not eligible | `"rejected_ineligible"` | Blocking reasons from eligibility check |
| No governance ID | `"rejected_no_governance"` | `"Governance decision ID is required"` |
| L3→L4 without verifier | `"rejected_no_verifier"` | `"L3→L4 promotion requires verifier_id"` |

## 7. Decay Engine API Surface

**Source:** `memory/ontology/decay_engine.py`

### Data Classes

**`DecayReport`** — Fields: `entry_id`, `layer`, `previous_confidence`, `new_confidence`, `decay_reason`, `below_threshold`, `recommended_action`

### DecayEngine Class

Constructor: `DecayEngine(rules: list[DecayRule], confidence_model: ConfidenceModel)`

| Method | Signature | Description |
|--------|-----------|-------------|
| `apply_time_decay(entries, current_time)` | `(list[Any], datetime) → list[DecayReport]` | Exponential time-based decay |
| `apply_inactivity_decay(entries, current_time)` | `(list[Any], datetime) → list[DecayReport]` | Accelerated decay for inactive entries |
| `apply_contradiction(entry, evidence)` | `(Any, str) → DecayReport` | Immediate contradiction penalty |
| `apply_failed_reuse(entry, context)` | `(Any, str) → DecayReport` | Failure penalty on bad outcome |
| `sweep(entries, current_time)` | `(list[Any], datetime) → list[DecayReport]` | Full pass: time + inactivity + threshold |
| `get_at_risk_entries(entries, current_time)` | `(list[Any], datetime) → list[DecayReport]` | Entries within 0.1 margin of removal |
| `generate_report(reports)` | `list[DecayReport] → str` | Human-readable summary grouped by action |

### Recommended Actions

| Action | Condition |
|--------|-----------|
| `"remove"` | `new_confidence <= min_confidence` |
| `"archive"` | `margin < 0.1` (within 0.1 of minimum) |
| `"retain"` | Otherwise |

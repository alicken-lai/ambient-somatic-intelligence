## 3. Bus Connections (7 v0.4 connections)

**Source:** `integration/v04_wiring.py`

All connections are fault-tolerant (wrapped in `try/except`). Each is independently wirable — partial failures do not block other connections.

### Connection 1: `somatic_to_salience`

- **Source:** `SomaticSignalBus.on_any` callback
- **Target:** `attention.SalienceEngine.compute_salience()`
- **Mechanism:** Callback (the only non-monkey-patch connection)
- **Behavior:** Converts `SomaticSignal` to `AttentionSignal` with normalized `raw_value` (0.0–1.0), then computes salience
- **Wiring function:** `_wire_somatic_to_salience()`

### Connection 2: `escalation_to_audit`

- **Source:** `attention.EscalationRouter.evaluate`
- **Target:** `governance.AuditLog.record_decision()`
- **Mechanism:** Monkey-patch of `evaluate` method
- **Behavior:** When escalation action is `ESCALATE`, records decision to governance audit log with risk `"REVIEW_REQUIRED"`
- **Wiring function:** `_wire_escalation_to_audit()`

### Connection 3: `skill_router_to_attention`

- **Source:** `skills.SkillRouter.execute_with_fallback`
- **Target:** `attention.SalienceEngine.compute_salience()`
- **Mechanism:** Monkey-patch of `execute_with_fallback` method
- **Behavior:** Emits `skill_execution_started` signal before execution and `skill_execution_completed` signal after, with timing data
- **Wiring function:** `_wire_skill_router_to_attention()`

### Connection 4: `episode_store_to_memory`

- **Source:** `memory.somatic.SomaticEpisodeStore.store`
- **Target:** `memory.MemoryKernel.store()`
- **Mechanism:** Monkey-patch of `store` method
- **Behavior:** Bridges episodes with severity `"high"` or `"critical"` to the memory kernel's `"episodic"` layer with `[somatic, auto-bridged, <severity>]` tags
- **Wiring function:** `_wire_episode_store_to_memory()`

### Connection 5: `precursor_to_attention`

- **Source:** `memory.somatic.PrecursorMatcher.match`
- **Target:** `attention.SalienceEngine.compute_salience()`
- **Mechanism:** Monkey-patch of `match` method
- **Behavior:** Precursor matches with `confidence >= 0.5` are converted to `AttentionSignal` with `source_domain="somatic_memory"`, `signal_type="precursor_detected"`, and `governance_relevant=True` metadata
- **Wiring function:** `_wire_precursor_to_attention()`

### Connection 6: `registration_to_governance`

- **Source:** `agents.skillify.SkillRegistrationPipeline.propose`
- **Target:** `governance.AuditLog.record_decision()`
- **Mechanism:** Monkey-patch of `propose` method
- **Behavior:** Logs every skill proposal to governance audit trail with risk `"REVIEW_REQUIRED"` and policy `"skillify_governance"`
- **Wiring function:** `_wire_registration_to_governance()`

### Connection 7: `observer_to_miner`

- **Source:** `agents.skillify.WorkflowObserver.observe`
- **Target:** `agents.skillify.SkillifyPatternMiner.mine()`
- **Mechanism:** Monkey-patch of `observe` method
- **Behavior:** Every 5 accumulated events (when `len(events) % 5 == 0`), triggers pattern mining with `min_support=3`
- **Wiring function:** `_wire_observer_to_miner()`

## 4. Boot Sequence

**Source:** `integration/v04_boot.py` and `integration/v031_boot.py`

**Execution order:**

1. **Skills Layer** — instantiate `SkillValidator` → `SkillRegistry(validator)` → `SkillRouter(registry)`

3. **Somatic Memory Layer** — instantiate `SomaticEpisodeStore`, `EnvironmentalSignature` (class ref), `PatternSimilarity`, `PrecursorMatcher`
4. **Skillify Layer** — instantiate `WorkflowObserver`, `SkillifyPatternMiner`, `SkillCandidateGenerator`, `SkillRegistrationPipeline`
5. **Wire v0.4 connections** — call `wire_v04(kernel, kernel.integration_bus, v04)` → establishes all 7 connections
6. **Register default skills** — 7 skills from `skills.system`, `skills.sensing`, `skills.cognition`, `skills.governance`

## 6. Backward Compatibility

**Guarantees from `integration/integration_map.py`:**

1. v0.2 `IntegrationBus.wire()` connections remain unmodified and active
2. v0.3 `IntegrationBus.wire_v03()` connections remain unmodified and active
3. v0.4 does NOT modify `kernel/__init__.py`, `kernel/integration_bus.py`, or `kernel/bootstrap.py`
4. v0.4 boot is additive — call `boot_v04(kernel)` after `boot()` and `boot_v03()`
5. v0.4 wiring uses the same `_log_event()` method for consistent event logging
6. v0.4 event schemas extend `EventSchemaRegistry`; v0.2/v0.3 schemas remain intact
7. All v0.4 connections use `try/except` — partial failures do not block other connections
8. `SomaticSignalBus.on_any` callback is purely additive (no monkey-patching of `bus.emit`)
9. `SkillRouter.execute_with_fallback` monkey-patch preserves the original method's contract
10. v0.3.1 ontology layer is purely additive — no v0.4 modules are modified
11. v0.3.1 `boot_ontology()` runs AFTER `boot_v04()` and does not interfere with existing wiring

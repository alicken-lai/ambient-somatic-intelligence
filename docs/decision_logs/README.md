# Decision Logs

Decision logs preserve governance decisions that future contributors must be able to replay.

Use this filename format:

`YYYY-MM-DD-title.md`

## Template

```markdown
# YYYY-MM-DD Title

## Decision

What was decided?

## Reason

Why was this decision made?

## Alternatives

What alternatives were considered?

## Risks

What risks remain?

## Rollback

How can this decision be reversed, disabled, or contained?

## Approval

Who approved or reviewed the decision?
```

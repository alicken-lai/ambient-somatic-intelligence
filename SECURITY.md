# Security Policy

## Reporting Safety Issues

If you find a safety issue, privacy leak, or possible secret exposure, report it through the repository maintainer before publishing it publicly.

Include:

- what you found
- where it appears
- why it matters
- whether it is still present in the current working tree

## Prohibited Contributions

- credential extraction
- bypassing Guardian
- unsafe CUA automation
- destructive scripts

Do not submit changes that weaken the approval boundary, remove logging, or add hidden external execution paths.
